# テクテクてんぷる 🐾

ラグドールのてんぷるが、毎日の歩数をやさしく受け止めてくれるiPhone向けWebアプリです。
お金はかかりません。死んだり、すねたり、育成のノルマもありません。

- 歩数は iPhone の「ヘルスケア」から「ショートカット」が読み取って、アプリに届けます
- 季節・祝日・行事（猫の日、十五夜、クリスマスなど）・曜日・時間帯・歩いた量に合わせて、その日のひとことが変わります（約500種類、ボソボソした敬語。同じ言葉は1週間なるべく出ません）
- 時間でポーズが変わります（早朝・朝はのび、昼はおすわり、よく歩いた日は立ちポーズ、夕方はうしろ姿、夜は香箱で寝る）
- 季節の小物：ハロウィンの帽子、クリスマスの帽子、冬のマフラー、夏の麦わら帽子、春の桜の花びら
- 日曜日は「今週のふりかえり」が出ます
- 📰 ニュースの帯：絵の下に、経済・主なニュース・国際の見出しが流れます（スポーツは入れません）。押すと一覧が開き、見出しを押すと元の記事が開きます。見出しは GitHub が30分ごとに集めます（設定は下の「ニュースを流すための設定」）
- ☂ 中野区の天気：右上に今日の天気・気温・降水確率が出て、空も雨・雪・くもりに変わります。天気に合わせたひとことも出ます。天気を押すと1週間の予報が見られ、日を押すと1時間ごとの天気が見られます（Open-Meteo の無料予報。電波がないときは、最後に取れた天気を出します）
- てんぷるをタップすると、びっくりして立ち上がります
- 📅 おさんぽ日記：歩いた日に肉球スタンプがつくカレンダー
- 設定：ねこの名前・お誕生日（当日はお祝いになります）・歩数の手入力
- データはそのiPhoneの中だけに保存されます

## 1. GitHub Pages で公開する（無料・Macのブラウザでできます）

1. https://github.com でアカウントを作ります（無料）。
2. 右上の「＋」→「New repository」を押します。
3. Repository name に `tekuteku-temple` と入れ、**Public** を選んで「Create repository」を押します。
4. 次の画面にある「uploading an existing file」というリンクを押します。
5. このフォルダ（`tekuteku-temple`）の**中身**をすべて選んで、ブラウザにドラッグします。
   `index.html` や `icons` フォルダなどが、いちばん上の階層に並ぶようにしてください（フォルダごとではなく中身を入れるのがポイント）。
6. 下の「Commit changes」を押します。
7. リポジトリの「Settings」→ 左のメニューの「Pages」を開きます。
8. 「Build and deployment」の Source を「Deploy from a branch」、Branch を「main」と「/(root)」にして「Save」を押します。
9. 1〜2分待つと、次のアドレスで開けるようになります。

   `https://（あなたのGitHubユーザー名）.github.io/tekuteku-temple/`

   iPhoneのSafariで開いて、てんぷるが表示されればOKです。

> ひとことを書き足したいときは、GitHub上で `messages.js` を開き、鉛筆アイコンで編集して「Commit changes」を押すと反映されます。

## 2. 歩数を届けるショートカットを作る（iPhone）

1. 「ショートカット」アプリを開き、右上の「＋」を押します。
2. 下の検索欄で **「ヘルスケアサンプルを検索」** を探して追加します。
   - 「すべてのヘルスケアサンプル」の部分をタップして **「歩数」** を選びます。
   - 条件が **「開始日」が「今日」** になっていることを確認します。
   - 「グループ化」を **「日」** にします（iPhoneとApple Watchの歩数が二重に数えられるのを防ぎます）。
3. 検索欄で **「統計を計算」** を探して追加し、**「合計」** にします。
4. 検索欄で **「URL」** を探して追加し、次のように入力します。

   `https://（あなたのGitHubユーザー名）.github.io/tekuteku-temple/?steps=`

   続けて、キーボードの上に出る変数の候補から **「統計」**（3で計算した合計）をタップして、URLの最後にくっつけます。
5. 検索欄で **「URLを開く」** を探して追加します。
6. いちばん上の名前を「テクテクてんぷる」に変え、アイコンの色や絵を好きに選びます。
7. 一度 ▶︎ を押して試します。初回は「ヘルスケアへのアクセス」をたずねられるので「許可」してください。
   Safariでてんぷるが開いて「◯◯歩、とどいたよ！」と言えば成功です。

### ホーム画面に置く

ショートカットの編集画面で、下の「共有」ボタン →「ホーム画面に追加」を選びます。
これで、アイコンをタップするだけで「今日の歩数を届けて、てんぷるに会う」ができます。

> **大事なこと**：Safariの共有メニューからアプリ自体を「ホーム画面に追加」することもできますが、iPhoneではSafariとホーム画面アプリで保存場所が別々になります。ショートカットはいつもSafariで開くので、**ホーム画面にはショートカットのほうを置く**のがおすすめです。

### 毎晩、自動で届ける（おこのみで）

1. ショートカットアプリ下の「オートメーション」→ 右上「＋」を押します。
2. 「時刻」を選び、たとえば「21:00」「毎日」にして、「すぐに実行」を選びます。
3. 次へ進み、「ショートカットを実行」で「テクテクてんぷる」を選びます。

※ iPhoneがロック中だと、Safariが開くのはロックを解除したあとになることがあります。

## ニュースを流すための設定（最初の1回だけ）

ニュースの見出しは、GitHub が30分ごとに NHK・Yahoo!ニュース・Google ニュースから集めて `news.json` に書きます。公開しているリポジトリなら無料です。

1. いつもどおり、zip の中身（`news.js`・`news.json`・`tools` フォルダを含む）をリポジトリにアップロードします
2. 集める係の設定ファイルを作ります。Mac では `.github` フォルダが見えないことがあるので、GitHub の画面で作るのが確実です
   - リポジトリの画面で「Add file」→「Create new file」
   - 名前の欄に `.github/workflows/news.yml` と入力（`/` を打つとフォルダになります）
   - 中身の欄に、zip の中の `.github/workflows/news.yml` の中身をそのまま貼る（下にも同じものがあります）
   - 「Commit changes」を押す
3. 上のメニューの「Actions」を開き、「ニュースを集める」→「Run workflow」を押します。1〜2分で緑のチェックがつき、`news.json` に見出しが入ります
4. そのあとは30分ごとに自動で動きます。アプリを開くと、絵の下にニュースが流れます

うまくいかないとき：
- 「Actions」の画面で、使えるようにするボタンが出ていたら押してください
- 赤い × がついたときは、Settings → Actions → General の一番下「Workflow permissions」を「Read and write permissions」にして保存し、もう一度「Run workflow」を押してください
- 赤い × を押すと、どのニュースサイトが取れなかったかが書いてあります

<details><summary>news.yml の中身</summary>

```yaml
# 30分ごとにニュースの見出しを集めて news.json を更新する
name: ニュースを集める
on:
  schedule:
    - cron: '7,37 * * * *'
  workflow_dispatch:
permissions:
  contents: write
concurrency: news
jobs:
  news:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: actions/setup-node@v5
        with:
          node-version: 24
      - run: node tools/news.mjs
      - name: 変わっていたら保存
        run: |
          if git diff --quiet -- news.json; then echo "変わりなし"; exit 0; fi
          git config user.name "github-actions[bot]"
          git config user.email "41898699+github-actions[bot]@users.noreply.github.com"
          git add news.json
          git commit -m "ニュースを更新"
          git push
```

</details>

## 3. 困ったときは

- **歩数が「—」のまま**：ショートカットを ▶︎ で実行してみてください。うまくいかないときは、設定 の「歩数を手で入れる」でも入れられます。
- **歩数が実際と違う**：ショートカットの「グループ化」が「日」になっているか確認してください。
- **記録のバックアップ**：設定 の「記録のバックアップ」で「コピー」を押し、メモ帳アプリなどに貼っておきます。記録が消えたら、その文字を同じ欄に貼って「もどす」を押してください。
- **天気が出ない**：天気はネットにつながっているときに取ってきます（30分ごと）。一度も取れていないうちは表示されません。
- **記録が消えた**：Safariの履歴やWebサイトデータを消すと記録も消えます。また、iPhoneのSafariは「7日以上ひらかれなかったサイト」のデータを消すことがあります。てんぷる自体はいなくならないので、また今日から一緒に歩けば大丈夫です。

## ファイルの中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面とてんぷるの絵 |
| `style.css` | 見た目・アニメーション |
| `app.js` | 歩数の受け取り・保存・ひとことの組み立て |
